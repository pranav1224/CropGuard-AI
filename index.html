CropGuard: Project Synopsis

Project Title

CropGuard: An Integrated Deep Learning and Agro-Climatic Decision Support System for Real-Time Plant Pathology Diagnosis and Precision Yield Optimization.

1. Abstract & Introduction

Agricultural yield loss caused by undetected plant disease pathogens accounts for over 20-40% of global crop losses annually. Traditional manual inspection by agronomists is geographically limited, cost-prohibitive, and often leads to excessive indiscriminate pesticide usage that degrades soil health. CropGuard presents a comprehensive solution built using the MERN (MongoDB, Express, React, Node.js) stack coupled with a high-performance FastAPI/PyTorch machine learning microservice.

2. Core Objectives

  • Real-time Leaf Pathology Diagnosis: Achieve >98% accuracy across 38 crop disease classes using lightweight transfer-learned MobileNetV3 and ResNet architectures.
  • Explainable AI (XAI): Generate Grad-CAM attention heatmaps showing exactly which leaf region dictated the diagnostic prediction to ensure agronomist trust.
  • Agro-Climatic Yield Forecasting: Ensemble regression modeling (XGBoost/Random Forest) forecasting crop yield in tons/acre based on soil Macronutrients (N, P, K), pH, temperature, and rainfall.
  • Organic-First Prescription Engine: Automatically recommend non-toxic, biological biocontrol agents and organic remedies prior to proposing targeted synthetic chemical treatments.

3. Technology Stack

Frontend: React 18, Tailwind CSS, Chart.js, HTML5 Canvas, Lucide Icons
Backend API: Node.js, Express.js, JWT, Multer, REST Architecture
Machine Learning: Python 3.10+, PyTorch, Torchvision, ONNX Runtime, XGBoost, Scikit-Learn
Database & Cloud: MongoDB Atlas (NoSQL), Cloudinary for image storage

4. Datasets Utilized

  • PlantVillage Dataset: 54,305 high-resolution leaf photographs across 14 crops and 38 classes (Apple Scab, Tomato Late Blight, Potato Early Blight, Corn Common Rust, etc.).
  • Crop Recommendation & Soil Dataset: 2,200 agricultural field records correlating N, P, K, pH, rainfall, and temperature with crop viability and yield.
  • Agmarknet Mandi Dataset: Live commodity spot price timeseries across Indian wholesale agricultural markets.
